1. How to create  logical volume out of some physical volume and create some filesystem out of that and mount it somewhere in the virtual directory?


1. Physical volume(PV)
2. Volume group (VG)
3. Logical Volume (LV)
4. Filesystem
5. Mounting


To check disks: lsblk


Step 1: Creating pv using command sudo pvcreate /dev/sdb
Can verify using pvs


Step 2: Create volume group using command sudo vgcreate vg_data /dev/sdb
Can verify using vgs


Step 3: Create 10gb logical volume using command sudo lvcreate -L 10G -n lv_data vg_data
Can verify using Lvs


Step 4: Create a filesystem using command sudo mkfs.ext4 /dev/vg_data/lv_data 


Step 5: Create a mount point using command sudo mkdir /data


Step 6: Mount the lvm storage using command sudo mount /dev/vg_data/lv_data /data




2. We can Unmount the data using sudo umount /mnt/data
